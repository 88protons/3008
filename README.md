# 3008 Seed Map

so, basically, a seedmap for [3008](https://www.roblox.com/games/2768379856).

**[Open the map](https://88protons.github.io/3008/)**

runs DIRECTLY in the browser!

## what it will get right

every one of 49 pillars with their type (normal, construction, cracked, house, king's remains). literally every cafeteria and industrial shelf position, length and other stuff. plot coverage is 100%, every plot's spawn weight is worked out exactly.

literally enter a seed and boom, you got a map! literally that easy a baby could do it.

open src!! woo
